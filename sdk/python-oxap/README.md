# oxap

`pip install oxap` installs [`oxap-sdk`](https://pypi.org/project/oxap-sdk/), the Python SDK for the oxap runtime, at the same version. Import it as `oxap_sdk`.

The SDK talks to the `oxap` binary, which this package does not ship. Install the binary from the [releases](https://github.com/lsm/oxap/releases) or with `npm install -g @oxap/cli`.
